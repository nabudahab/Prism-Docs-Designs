# Prism documentation: design prototypes

Three alternative front ends for the Prism documentation site, for review:
Datasheet (engineering reference), Coursebook (course text) and Exploded view
(platform site). Each is a complete, navigable site over the same content.

The built sites are published from the `gh-pages` branch; start at its
`index.html`, which compares the three with the current site.

`designs/README.md` explains how the designs are built from the canonical
site and how to rebuild them from a Prism-Website checkout.
