# Prism documentation: design prototypes

Alternative front ends for the Prism documentation site, for review. Each is a
complete, navigable site over the same content.

- Three directions: Datasheet (engineering reference), Coursebook (course
  text) and Exploded view (platform site).
- Two unified designs built blind from parts of those three: Unified A
  (Claude Opus 5.5) and Unified B (GPT-6.1 Sol), each then revised after the
  other's review.
- Unified C: Unified B revised with one serif type system and folding
  contents, in seven colour palettes with light and dark themes (Unified B's own
  palette, three by Claude Opus 5.5 and three by Claude Fable 5.2).

The built sites are published from the `gh-pages` branch; start at its
`index.html`, which shows every design side by side with the current site.

`designs/README.md` explains how the designs are built from the canonical
site and how to rebuild them from a Prism-Website checkout.
